Is the workspace learning, or just hoarding?

Every memory layer audited: mempalace, auto-memory, .remember/, session notes, CLAUDE.md tiers, and the hooks between them — with all 114 workspace transcripts mined for what actually resurfaces.

Verdict

ACCUMULATING. The workspace gets smarter only through its always-loaded file layers (CLAUDE.md, MEMORY.md, .remember injection). The 20,155-drawer semantic layer is noise-dominated, re-serves stale facts as truth, and cannot say which memories are ever used — nothing tracks retrieval.

Findings

Critical

F1 · Recall channel is noise-dominated

87% of injections from wholesale-ingested docs; dead projects supply 27%; median sim 0.49 vs threshold 0.30 (max 5 results, hooks/lib.sh:37).

Critical

F2 · Nothing tracks whether a memory is ever used

No hit counting in the mempalace package, the HTTP server, or its log (46,635 lines, zero request records). Usage-informed decay and promotion are impossible until this primitive exists.

Critical

F3 · Stale facts re-served as truth

Top result for the chorestory-RLS query (0.967 after a +0.4 closet_boost) is a Nov-2025 aspirational doc claiming DB-level RLS — ranked above verified reality. Backfilled drawer still says “INERT in BOTH dev and prod”; dev flipped live 07-03. One expired fact palace-wide.

High

F4 · Auto-memory is 82% write-only

217 body files; 40 ever read across 114 sessions. Index at its ~5k-token budget; 2 orphans; laptop merge introduced a flagged contradiction.

High

F5 · Delivery silently truncates >10 KB

Both memory systems’ injections overflowed the harness inline limit in one day and arrived as file pointers with 2 KB previews. Nothing alerts.

High

F9 · Recall scoping wrong under concurrency

resolve_project() picks the globally most-recent project, not this session’s binding; the basename(cwd) fallback mints bogus wings (prompts, tmp, docs observed).

High

F10 · Duplication is systemic; dedup can’t see it

The memory-policy fact lives in ≥6 places. Backfill dedup at 0.9 over full file text flagged zero duplicates in 197 files that contained ≥4 copies of one fact.

Medium

F6–F8 · The healthy parts, and their ceiling

.remember has the only complete capture→decay→resurface pipeline, but insights die in archive.md instead of promoting. session_notes work only where an always-loaded pointer names the file (42/56 write-only). Guaranteed session-start load is 18.1k tokens — the promotion budget is already spent.

The promotion ladder (design)

One home per fact; a fact climbs one rung at a time, and each rung has an entry criterion. Demotion is the same ladder downward.

L0 · capture.remember/today-*.mdanything notable · existing staging
L1 · consolidaterecent.md → archive.mdsurvives Haiku merge · existing
L2 · durablemempalace drawer / KGrecurred ≥2 sessions, or burned >30 min, or cross-project
L3 · indexedMEMORY.md lineproven reuse · budget-gated (~120 lines)
L4 · contractCLAUDE.md ruleit is process · owner PR only
